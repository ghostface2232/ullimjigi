# 울림지기 — 하늬 골짜기의 노래

젤다의 전설: 야생의 숨결 풍의 셀 셰이딩 3D 3인칭 마법사 액션 어드벤처. 웹 브라우저에서 실행됩니다.
모델·텍스처·효과음·음악은 모두 코드로 생성합니다 (외부 에셋 없음, `public/fonts`의 폰트만 사용).

## 실행

```bash
npm install
npm run dev
```

브라우저에서 표시된 주소(기본 `http://localhost:5188`)를 엽니다. 헤드폰을 권장합니다.

배포용 빌드는 `npm run build` → `dist/` 폴더를 정적 서버로 서빙하면 됩니다 (`npm run preview`로 확인).

## 조작

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| 마우스 | 시점 · 조준 (화면 클릭 시 마우스 고정) |
| Shift 누르기 / 짧게 | 달리기 / 순간이동(회피, 무적) |
| Space | 점프 · 공중에서 누르고 있기: 활공 |
| 좌클릭 / 우클릭 | 기본 마법(누르고 있다가 떼면 모아 쏘기) / 고유 마법 |
| Q | 엮기 — 현재 속성 + 직전 속성 융합 마법 |
| F | 궁극기 — 울림 게이지가 가득 찼을 때 |
| 1~6 / 휠 | 속성 전환 (비전·화염·바람·서리·번개·물) |
| K | 울림 나무 (스킬 트리) |
| T / 휠 클릭 | 대상 고정 |
| E | 대화 · 조사 · 등석 |
| M / Tab / Esc | 지도(등석 클릭 시 빠른 이동) / 여정·마법서 / 일시정지 |

## 시스템 요약

- **속성 6종 × (기본 마법 + 모아 쏘기 + 고유 마법 + 궁극기)**, 두 속성을 엮는 **융합 마법 11종**
- **땅의 흔적**: 불길·서리밭·물웅덩이·김 구름·대전된 땅이 마법과 반응 뒤에 남고, 다른 속성을 더하면 전류 웅덩이·번개 안개·들불·빙판 같은 다른 흔적으로 바뀜 (변화 23종, 도감 기록)
- **울림 나무**: 속성마다 갈래가 나뉘는 스킬 트리 6그루 + 두 속성을 잇는 조화의 나무. 레벨업·보스·수집으로 얻는 울림점으로 익힘, 언제든 되돌리기 가능
- **원소 반응 17종**: 융해, 증발, 열충격, 순간 빙결, 파쇄, 감전 연쇄(감전 지속 피해), 과부하, 화염 확산, 눈보라, 뇌전 확산, 소화(역효과), 끓는 김, 누전, 초전도, 장대비, 공명, 공중 강타 · 반응 도감 · 연쇄 반응 보너스
- **완벽 회피**: 공격 직전 순간이동하면 울림 가속(슬로모션)
- 환경 상호작용: 불로 화로·등석 밝히기, 바람으로 바람개비 돌리기, 서리로 물 위 얼음 발판
- 적: 허깨비 · 울음탈 · 돌무덤 · 잿물(분열, 불/서리 변종) · 재나방 + 서리 변종, 보스 3종 (서리무덤 파수꾼 · 무명의 기사 · 이름 삼킨 자)
- 레벨 단계 명칭: (기본) → 해묵은 → 잊힌 → 이름 없는 · 정예 개체는 고유 이름
- 이야기 진행도와 플레이어 레벨을 함께 반영하는 적 레벨링
- 수집: 노래 씨앗 16개(4개마다 능력 상승), 모라의 기억 4개, 곁가지 이야기(누룽지, 이름 붙은 것들, 거울 호수의 메아리)
- 낮/밤 순환, 지역별 적응형 음악, 등석(체크포인트·휴식·빠른 이동), 이야기 진행 시 자동 저장
- 그래픽: 대기 원근과 구름 그림자, 지역별 수종과 지피 식생, 조형·스키닝된 캐릭터와 적(표정·몸짓·2차 움직임), 지형을 따르는 마법 흔적과 속성별 이펙트, 방향성 카메라 반동
- 대화: 표정·몸짓 연기, 카메라 블렌드, 지난 대사(L), 길게 눌러 넘기기(Esc)

## 개발용

URL에 `?dev=<프리셋>`을 붙이면 타이틀을 건너뛰고 해당 장으로 바로 시작합니다:
`1`(프롤로그), `village`, `bells`, `lake`, `frost`, `storm`, `mora`, `rift`, `skills`(스킬 테스트), `continue`(저장 불러오기).

## 폰트

`public/fonts/`에 포함된 폰트입니다. 각 폰트의 저작권은 제작사에 있습니다. 저장소를 공개하거나 게임을 배포하기 전에 배포처의 라이선스(재배포·웹 임베딩 허용 여부)를 확인하세요.

| 폰트 | 파일 | 쓰는 곳 |
|---|---|---|
| 빛의계승자체 | `HeirofLightOTF*.woff2` | 게임 제목, 지역 이름, 배너 |
| 연단된칼날체 (DNF Forged Blade) | `DNFForgedBlade-*.woff2` | 부제, 스킬·아이템 이름, 버튼, 피해 숫자 |
| 함렛 (Hahmlet) | `Hahmlet-*.woff2` | 대사, 본문 |

UI 보조 서체로 Google Fonts의 Gowun Dodum, Cinzel을 불러옵니다.
