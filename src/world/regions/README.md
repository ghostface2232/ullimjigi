# 바깥 지역 데이터

골짜기 둘레 산맥 너머의 땅을 지역마다 파일 하나로 정의합니다. 새 지역은 파일을 만들고 `index.js`의 `OUTER`에 넣으면 지형·채색·기후·음악·지역 이름이 모두 따라옵니다.

| 필드 | 뜻 |
|---|---|
| `id`, `name`, `en` | 식별자, 지역 이름(한국어·영문). 사이 땅은 `name: null`(이름 표시 없음) |
| `dir` | 골짜기 중심에서 본 방향(도, 0 = 동, 90 = 남, −90 = 북). 바깥 땅은 이 방향들 사이를 부드럽게 섞습니다 |
| `lv` | 지역 레벨(야영지 적 레벨의 바탕) |
| `music`, `climate` | 음악 분위기, 날씨 가중치(`clear`·`cloudy`·`rain`·`storm`) |
| `label` | 큰 지도에 이름을 쓸 자리 `[x, z]` |
| `height(x, z, f)` | 지면 높이. `f`: 공용 노이즈 값(`b` 넓은 기복, `d` 잔기복, `rg` 능선)과 노이즈 함수(`n`·`n2`·`n3`) |
| `paint(c, k, f, P)` | 선택. 지형 색 `c`(THREE.Color)를 이 지역 비중 `k`만큼 바꿈. `f.dry` 등, `P`는 팔레트 |

바다(남쪽 해안선)와 맵 가장자리 산맥은 지역과 상관없이 `terrain.js`가 얹습니다.
